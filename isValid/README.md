## Commit Convention

Each solution is committed individually, matching LeetSync's auto-generated format:

```
<number>. <Title> - <Language>

Runtime: <time> ms, faster than <X>.00% of <Language> online submissions
Memory: <mem> MB, less than <Y>.00% of <Language> online submissions
```

One commit per problem, one folder per problem (`<number>-<slug>/<function>.c`), so the commit log itself is a running solve history.
